# PostgreSQL スキーマ設計

## 方針

- `started_at`、`ended_at`、`recorded_at` は `TIMESTAMP WITHOUT TIME ZONE` とし、JSTの壁時計時刻を保存する。
- PostgreSQL サーバーとアプリのタイムゾーンを `Asia/Tokyo` に設定する。
- チャンネルマスタは持たず、名前などは各テーブルに直接保存する。
- 初期スキーマは `docker/db/schema.sql` で管理する。

---

## `channel_sessions`

チャンネルがインメモリStoreに存在している期間（配信セッション）を記録する。芝生グラフの配信時間合計の集計元。

```sql
CREATE TABLE channel_sessions (
    id           BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    channel_name VARCHAR(255) NOT NULL,
    genre        VARCHAR(255) NOT NULL DEFAULT '',
    url          VARCHAR(255) NOT NULL DEFAULT '',
    description  VARCHAR(255) NOT NULL DEFAULT '',
    comment      VARCHAR(255) NOT NULL DEFAULT '',
    content_type VARCHAR(32)  NOT NULL DEFAULT '',
    tracker_ip   VARCHAR(45)  NOT NULL DEFAULT '',
    started_at   TIMESTAMP WITHOUT TIME ZONE NOT NULL,
    ended_at     TIMESTAMP WITHOUT TIME ZONE NULL
);

CREATE INDEX idx_channel_name ON channel_sessions (channel_name);
```

- `channel_name`、`genre`、`url`、`description`、`comment` はセッション開始時の情報を記録する。
- `tracker_ip` はセッション開始時点の配信者ノードのIPアドレス。
- `ended_at` が `NULL` の行は配信中。起動時のクラッシュリカバリで未終了セッションを閉じる。
- 配信時間は開始から終了までの区間を日付境界で按分する。

## `channel_snapshots`

10分間隔でインメモリStoreの状態を保存する。リスナー数推移グラフと日別タイムラインに使う。

```sql
CREATE TABLE channel_snapshots (
    id               BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    session_id       BIGINT NOT NULL,
    channel_id       CHAR(32) NOT NULL DEFAULT '',
    recorded_at      TIMESTAMP WITHOUT TIME ZONE NOT NULL,
    listeners        INTEGER NOT NULL DEFAULT 0,
    relays           INTEGER NOT NULL DEFAULT 0,
    age              BIGINT NOT NULL DEFAULT 0,
    name             VARCHAR(255) NOT NULL DEFAULT '',
    bitrate          INTEGER NOT NULL DEFAULT 0,
    genre            VARCHAR(255) NOT NULL DEFAULT '',
    url              VARCHAR(255) NOT NULL DEFAULT '',
    description      VARCHAR(255) NOT NULL DEFAULT '',
    comment          VARCHAR(255) NOT NULL DEFAULT '',
    content_type     VARCHAR(32) NOT NULL DEFAULT '',
    hidden_listeners BOOLEAN NOT NULL DEFAULT FALSE,
    track_title      VARCHAR(255) NOT NULL DEFAULT '',
    track_artist     VARCHAR(255) NOT NULL DEFAULT '',
    track_contact    VARCHAR(255) NOT NULL DEFAULT '',
    track_album      VARCHAR(255) NOT NULL DEFAULT ''
);

CREATE INDEX idx_session_time ON channel_snapshots (session_id, recorded_at);
CREATE UNIQUE INDEX idx_recorded_at_name ON channel_snapshots (recorded_at, name);
```

`recorded_at` と `name` の一意制約により、同じ時間枠の再記録は `ON CONFLICT` で既存行を更新する。タイムラインでは `LAG()` ウィンドウ関数を使い、前回スナップショットから配信情報が変わった行を検出する。
